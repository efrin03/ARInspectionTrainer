\# AR Industrial Equipment Inspection Trainer



A Unity 6 interactive inspection training app featuring procedural 3D machine models, interactive fault detection, UI tracking, and automatic CSV session logging.



\## Tech Stack \& Features

\- \*\*Engine:\*\* Unity 6 (URP)

\- \*\*Input System:\*\* Modern Unity Input System

\- \*\*Key Scripts:\*\* `ARInspectionTrainer.cs` (manages inspection logic, progress tracking, and CSV logs output to `%userprofile%\\AppData\\LocalLow`)

\- \*\*UI:\*\* Unity EventSystem with runtime progress feedback
